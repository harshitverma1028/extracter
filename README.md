# AI Video Learning Generator

Phase 1 foundation for the zero-cost MVP.

## MVP Features
1. Distinct video snapshots -> PDF
2. Video summary + important points
3. Questions generated from video
4. Complete Learning Package

## Stack
- React + JavaScript
- Node.js + Express
- MongoDB
- Ollama/local LLM (later)
- FFmpeg (later)
- PDF generation (later)

## Run backend
cd server
npm install
copy .env.example .env
npm run dev

## Run frontend
cd client
npm install
npm run dev

MongoDB must be running locally.
